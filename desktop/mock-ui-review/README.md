# 康复系统｜模式 A 免登录界面审查

这是**独立、离线、仅本机**的模拟用户界面，不是正式 Core、Owner 或 HEP 的免登录版本。直接打开主页，无需账户密码；与现有正式服务使用不同端口、不同数据源。

## Mac 启动

在 Finder 双击 `start.command`，或在本目录运行：

```bash
python3 -B server.py --port 17630
```

浏览器打开 **http://127.0.0.1:17630/**。在 Terminal 按 **Ctrl+C** 停止。第一次从互联网下载的脚本可能触发 macOS 的确认，请检查源码后再选择运行。

页面默认角色为“QA全功能预览”，可切换模拟机构管理员、治疗师、文员、患者及 Owner。全部人物、机构及病例均为**虚构演示对象**，ID 以 `DEMO-` 开头。模拟数据只存在浏览器本次页面运行内存，刷新网页即可重置，未使用 localStorage、Cookie 或远程存储。

## MVP 业务覆盖

首页、患者档案、疗程、初评/FMS 七项、报告草稿、康复计划、复评、HEP 动作与模板、模拟处方草稿、患者训练打卡（疼痛/RPE）、风险提醒、运动评估样例、Owner 模拟审批、运营和模拟审计。

页面中的“保存/提交/批准”只更改**虚构的本地演示状态**；没有签发临床文书、没有真实审核、没有上传真实视频、没有产生许可证、没有外网或局域网请求。

## 安全门禁

- HTTP 服务器**仅监听** `127.0.0.1`；只允许静态 GET/HEAD；POST/PUT/PATCH/DELETE/OPTIONS 全部返回 405。
- 白名单静态资源，不允许读取源码目录之外文件、环境变量、数据库、备份、token 或 .env。
- CSP `connect-src 'none'` 阻止浏览器脚本发出网络 API 请求；没有连接正式 Core/HEP/Owner。
- 没有修改正式服务的 OAuth2、JWT、TLS、租户隔离或临床签发校验。
- 模拟角色权限**只是界面效果**，不代表后端的真实权限安全；真实认证及租户边界必须在模式 B 独立验收。
- 不得将此 UI 上的“演示完成”自动记作原始 306 项业务验收 PASS。

## 快速验收步骤

1. 访问 `/` 应直接进入主页，并看到醒目的“模式A · 模拟数据 / 非正式系统”标识。
2. 打开患者档案：搜索、创建虚构患者，切换到疗程并创建演示疗程。
3. 打开初评：调整七项 FMS 评分并保存演示草稿；进入报告页查看、生成草稿。
4. 打开 HEP 治疗师页查看动作、模板和未签发处方；切换模拟患者身份，开始训练并记录疼痛/RPE。
5. 打开风险与审计页核查虚构事件，再重置演示数据。
6. 切换为模拟患者，尝试访问机构患者列表，应显示**模拟无权限**，而不是实际网络后端拒绝。

代码自测：`python3 -B -m unittest discover -s tests -v`。

## 交付限制

该项目是用于手工 UI 功能检查的最小可运行样本，**不是正式 Vue 系统的代码分支或 1:1 页面**。若要测试现有 Vue 页面自身的 UI 缺陷，后续应再建立隔离 Vue + Mock API 适配层并逐页替换；正式功能联调仍依赖 037 和授权身份。
