# 成员设备内部 CA 安装与验证

只分发 `deploy/internal/certs/ca.crt`。严禁分发 `ca.key`、`server.key`、`.env` 或
`backup.key`。

## macOS

1. 双击 `ca.crt` 导入“钥匙串访问”。
2. 将证书放入“系统”钥匙串。
3. 打开证书的“信任”，将“使用此证书时”设为“始终信任”；操作需要设备管理员授权。
4. 完全退出并重新打开浏览器。

## iPhone / iPad

1. 通过受控方式把 `ca.crt` 发送到设备并安装描述文件。
2. 在“设置 → 通用 → 关于本机 → 证书信任设置”中为该根证书启用完全信任。
3. 安装完成后删除聊天、邮件或下载目录中的临时证书副本。

## Windows

1. 打开 `ca.crt`，选择安装证书。
2. 选择“本地计算机”，将证书放入“受信任的根证书颁发机构”。
3. 重新启动浏览器。

## Android

在系统安全设置中从存储安装 CA 证书。不同厂商菜单名称不同；必须由设备持有人确认只安装本项目
提供的 `Rehab Internal Root CA`。部分浏览器或工作配置可能不信任用户 CA，这类设备验收不通过。

## 验证

- [ ] 访问 `https://部署机IP:8443`，地址栏没有证书警告
- [ ] 证书名称为部署机 IP，签发者为 `Rehab Internal Root CA`
- [ ] HTTP 地址自动跳转到 HTTPS
- [ ] 未安装任何私钥文件
