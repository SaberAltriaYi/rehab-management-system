# 防火墙与局域网交接记录

自动部署已将入口绑定到 `.env` 中的明确局域网 IP，并且只发布 8080（HTTPS 跳转）和
8443（HTTPS）。MySQL、Redis 和 Java 48080 端口没有主机映射。

本机检查时 macOS 应用防火墙尚未启用；此项需要设备管理员在系统设置中人工完成，不能由自动化
伪造为已完成。

## 上线前操作

1. 打开“系统设置 → 网络 → 防火墙”，启用防火墙。
2. 保留 Docker Desktop 必需的入站许可。
3. 在路由器管理界面确认没有 8080/8443 的公网端口转发、DMZ 或 UPnP 自动映射。
4. 从成员设备确认 `https://部署机IP:8443` 可访问。
5. 从成员设备确认部署机的 3306、6379、48080 不可访问。
6. 从非工作室网络确认 8080/8443 不可访问。
