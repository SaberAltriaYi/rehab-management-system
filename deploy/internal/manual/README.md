# 人工上线材料

这些表单用于记录自动化无法代替的人员、设备、保管位置与业务决策：

1. `CA_INSTALLATION.md`：成员设备证书安装和验证。
2. `ACCOUNT_AND_PERMISSION_REGISTER.md`：一人一号和最小权限登记。
3. `FIREWALL_NETWORK_HANDOFF.md`：主机防火墙、路由器和局域网边界。
4. `MEMBER_ACCEPTANCE.md`：至少两名成员的真实业务验收。
5. `OFFSITE_BACKUP_HANDOFF.md`：异地备份和独立密钥交接。
6. `GO_LIVE_SIGNOFF.md`：最终放行、责任人与回滚恢复点。

填写后的表单含姓名、账号和基础设施信息，应作为内部受控文档保存，不要提交到公共仓库。
