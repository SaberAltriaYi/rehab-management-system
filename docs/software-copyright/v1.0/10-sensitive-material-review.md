- 已移除后端默认配置中的硬编码 AES 密钥和 RSA 私钥示例，API 加密默认关闭；如后续启用只能从运行环境注入。

- 一键安装器只在部署设备本地生成随机管理员临时密码、基础设施密码、TLS 私钥和备份密钥。
- Git 忽略并发布排除 `.env`、证书私钥、备份密钥、备份目录、`FIRST_LOGIN.txt`、测试输出和发布输出。

## 患者数据结论

仓库未发现从生产环境导出的患者数据库、附件或备份。历史迁移包含三名明确标注为“演示数据”的合成患者及相应业务链路，用于早期开发；全新内部部署在服务启动前执行 `clean-demo-rehab-data.sql` 清空全部康复演示业务数据。

这些合成样本不应出现在软著截图、用户手册示例或生产数据库中。不得对已有真实业务库手工运行全量清理脚本。

## 自动门禁

`script/rehab/check-repository-sensitive-materials.sh` 检查：

- 私钥、证书密钥库、备份、压缩包、首次登录文件和运行期报告目录；
- GitHub、云平台、OpenAI、Slack 等高置信度令牌格式；
- PEM 与长 Base64 私钥特征；
- 前端默认登录信息、统计标识、地图/API 加密密钥；
- 数据库初始化脚本中未脱敏的对象存储访问凭据；
- 交付配置中的已知弱演示密码；
- 合成患者数据标识与全新部署清理脚本是否存在。

## 边界

上游测试代码和基础数据库脚本可能包含明确的非生产示例字符串、测试密码哈希和合成用户。它们不是实际凭据，且内部安装器会在对外启动服务前随机化管理员密码并加固登录客户端。若制作仅含自研代码的申请快照，应按自研清单排除这些上游示例文件。
