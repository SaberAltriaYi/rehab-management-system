# V1.0 功能清单

## 核心业务

1. 成员登录、验证码、会话、角色、菜单和数据权限。
2. 患者建档、查询、编辑、分配、转交、标签、CRM 绑定和操作记录。
3. 康复病程（Episode）创建、阶段维护和责任治疗师关联。
4. 静态评估、身体成分、NASM-CES、SFMA、FMS、YBT、OpenCap/专项评估。
5. 评估模块化保存、完成度校验、质量等级、操作日志和附件。
6. 综合报告生成、预览、复核、批准、锁版、版本记录及 DOCX/PDF 导出。
7. 康复计划创建、编辑、状态流转、训练任务与进阶/降阶提示。
8. 训练排期、签到、任务执行、疼痛和主观反馈记录。
9. 阶段进度汇总、依从性、疼痛趋势和人工结论。
10. 复评触发、到期提醒、确认和处理闭环。
11. 随访记录、成员通知、患者通知、风险预警和审计追踪。
12. 康复工作台、运营概览、待办和近期业务数据。
13. 系统用户、部门、岗位、角色、菜单、字典、日志和基础设施管理。
14. 数据库初始化、迁移校验、备份恢复、HTTPS、健康检查和局域网一键部署。

## 交付边界

- AI 相关代码来自既有项目演进，但 V1.0 的配置、菜单和界面入口均关闭，不作为申请功能亮点。
- 未交付独立预约日历模块；训练排期与复评到期由计划、任务和触发器承担。
- 商城、支付、IoT、BPM 等上游可选模块不属于 V1.0 康复业务交付范围。
- 系统为专业记录和业务管理工具，不输出医疗诊断结论。
