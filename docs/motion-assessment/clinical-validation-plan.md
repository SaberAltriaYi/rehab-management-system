# 临床验证计划与已知限制

系统当前定位：**辅助量化与记录工具**。所有自动结果都是建议，由治疗师确认、修改并签署；在本计划完成前，
派生/代理指标只作描述，不输出正常/异常/风险结论。

## 1. 验证目标

| 编号 | 问题 | 指标 | 通过标准（预设，需伦理与临床负责人确认） |
|---|---|---|---|
| V1 | FMS 系统建议分与认证评估者一致性 | 加权 κ、逐项一致率、7 项总分 ICC(2,1) | 逐项加权 κ ≥ 0.6；总分 ICC ≥ 0.75 |
| V2 | 自动判定条件（DS-02、肩灵活性比值、ASLR 位置）与人工判定一致性 | 灵敏度/特异度、误差带内比例 | 误差带外判定一致率 ≥ 90 %；误差带内全部转人工 |
| V3 | OpenCap 坐标与参照系统（标记式动捕或 IMU/量角器）一致性 | RMSE、Bland–Altman 95 % LoA | 报告即可；超过文献 4.5° / 12.3 mm 的关节与动作列为“仅人工” |
| V4 | 复测信度（同日/隔日） | ICC(3,1)、SEM、MDC95 | 各坐标 ROM/峰值给出 SEM 与 MDC；对比报告以 MDC 替代当前“测量误差带” |
| V5 | 阶段/重复识别 | 重复次数一致率、事件时刻误差 | 重复计数一致率 ≥ 95 %；事件误差 ≤ 2 帧 |
| V6 | 步态事件（Zeni）与力台/足底压力 | HS/TO 时刻误差、双支撑 % 误差 | 报告误差；跑台与地面分层 |
| V7 | TJA / LESS 自动候选与人工视频评分一致性 | κ（逐项）、总分 ICC | 未达标项保持人工 |
| V8 | AI 草稿质量与安全 | 证据引用正确率、越界语句率、治疗师采纳率 | 越界（诊断/改分/编造阈值）= 0；引用错误率 < 2 % |

## 2. 设计

* 前瞻性、单中心起步，伦理审批与知情同意（视频单独授权）；人群默认 18–60 岁、低风险门诊/运动人群
  （NASM 表 15 P1 待确认），排除急性损伤与禁忌动作者。
* 样本量：V1 以 κ = 0.6、95 % CI 半宽 0.15 估算约 60–80 名受试者 × 7 项；V4 至少 30 名 × 2 次。
* 评估者：2 名 FMS 认证治疗师独立现场评分（互盲、对系统结果盲），第三人仲裁；同步 2–4 台相机 OpenCap。
* 数据冻结：记录引擎、规则、协议版本与协议 SHA-256；验证期间不改规则。任何规则调整都产生新版本并需重新验证
  受影响部分。
* 分析：预先注册统计计划；按动作、侧别、相机数、场地分层；失败/无效试次单列，不剔除。

## 3. 上线分级

1. **阶段 A（当前）**：内部试用，全部结果需治疗师审核；报告标注“描述性量化、待验证”。
2. **阶段 B**：V1–V5 达标的条件可在界面标记“已本地验证”，仍需治疗师确认。
3. **阶段 C**：对 V3/V4 达标的指标开放 MDC 驱动的初评/复评“有意义变化”提示。

## 4. 已知限制

* OpenCap 相对标记式动捕平均误差约 4.5°（旋转）/ 12.3 mm（平移）（Uhlrich 2023, PLoS Comput Biol,
  doi:10.1371/journal.pcbi.1011462）；误差带内的判定一律交治疗师。
* LaiUhlrich2022 标准模型无独立肩胛、头颈、腕手自由度，膝仅屈伸：肩胛翼状、肩抬高、头前伸、木棒/栏架接触、
  手位、背后摸背等只能人工或代理。VTP 只是显示网格，不据此推断自由度。
* FMS 的木棒、栏架、测试板不在 OpenCap 输出中，相关条件（DS-05、HS-02/05、ILL-02/04、TSPU 手位）为人工。
* 肩水平外展（NASM 表 06）动作定义待确认；证据只展示 arm_add/arm_flex 原始坐标。arm_rot 正负方向需在本地
  设备上用已知动作确认（NASM 表 07）。
* 派生/代理指标（FPPA、足前进角、膝—足边界、足跟抬起、大腿角、双支撑 %、峰值时序）未经本地验证。
* 文献阈值（YBT 4 cm / 94 %、LESS > 5、FMS ≤ 14）来自特定人群，只作对照提示，不作风险判定。
* 团身跳/LESS 触地检测依赖足部标记高度（阈值 2 × 平移误差 + 最短腾空 0.1 s），落地声音等只能人工。
* 步态参数受跑台/地面、速度影响，需分层解读；OpenCap 帧率限制时序分辨率。
* 系统不做诊断、不给治疗处方；AI 内容是草稿，关闭 AI 不影响任何评分功能。
