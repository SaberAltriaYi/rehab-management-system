# 待确认项（NASM 表 15）与当前默认决定

以下问题来自 `NASM_CES_OpenCap_评估标准修订待确认版_V0.2.xlsx` 工作表 15。在临床负责人书面确认前，系统
按“默认决定”运行，全部可在协议 JSON 中调整并会产生新协议版本。

| 优先级 | 问题 | 默认决定 | 依据 / 当前状态 |
|---|---|---|---|
| P0 | 提供 `.mot` 表头以确认坐标名 | 按 LaiUhlrich2022 标准 33 坐标解析；按表头名称匹配，缺列记为不可用（不补 0） | 真实 OpenCap 样本已核对：模型 LaiUhlrich2022、坐标与工作表 14 一致 |
| P0 | 模型为标准版还是扩展版（含肩胛/头颈） | 标准版；肩胛/头颈/腕手检查点仅人工 | 若将来使用扩展模型，需要新增坐标映射并重新验证 |
| P0 | 是否提供 `.trc` 标记数据 | 默认提供；缺失时依赖标记的派生指标（FPPA、足前进角、足跟抬起、触地检测）降级为人工 | 真实样本含 `.trc` |
| P1 | 适用人群 | 18–60 岁低风险人群；其他人群报告加“人群外使用”提示 | 文献阈值来源人群不同，仅作对照 |
