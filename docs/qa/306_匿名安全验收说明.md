# 306 项：匿名访问与跨站来源的可重复实操

## 验证范围

`script/rehab/qa_306_anonymous_matrix.py` 是针对真实本机服务的**只读、无身份**操作脚本，主要补全：

- T-044：Owner 9444 上 `/owner/v1/applications` 的非法来源 GET 与 OPTIONS 必须拒绝；合法 HTTPS 来源的匿名 GET 仍须拒绝登录访问。
- T-243：内部 Core 患者、疗程、评估、报告、计划、用户列表；独立 HEP 管理员/治疗师/患者的页面数据与处方列表；Motion 8806 的评估/附件接口，未经身份验证均不得泄漏数据。
- T-147：独立 Motion 8806 登录界面须另用**无 cookie 的隔离浏览器**实测；脚本的 Motion 401 只证明 API 匿名拒绝，不替代浏览器或默认账号检查。

## 执行

在 Mac 的 `rehab-management-system` 仓库根目录：

```bash
umask 077
python3 -B script/rehab/qa_306_anonymous_matrix.py > /tmp/rehab-306-live-anonymous.json
```

要求脚本退出码为 `0`、每项记录均为 PASS；脚本只用 GET、OPTIONS，对 Owner 使用系统默认 HTTPS 严格证书校验，对内部 Core 只从已存在的 `rehab-studio-internal-server-1` 容器内使用私有回环 HTTP。**绝不能**将旧端口 48080 在宿主机的请求结果当作当前内部 Core；**不能**关闭 TLS 验证，也不能向此脚本加入真实账号、患者标识或令牌。

运行前确认独立 HEP 和 Motion 服务对应当前目标；服务无法连接、路由不匹配、空响应或 TLS 不可信应报告失败，不得把 404 当作匿名安全通过。日志仅保存请求标签、HTTP 状态和脱敏断言结果，不保存患者正文、密码、令牌或会话。

## 验收边界

这份脚本通过仅代表**所列匿名访问与来源校验**。T-008 严格 HTTPS、T-172 HEP 037 正式集成、Owner 正向 MFA、正常治疗师/患者会话、跨租户/跨患者及临床报告签发需要单独验收，不因本脚本通过而自动通过。
