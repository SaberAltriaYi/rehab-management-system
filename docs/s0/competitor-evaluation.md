## 固定虚构案例

- 档案：`S0-SYNTH-ADULT-A`，30岁，完全虚构成人。没有手机号、真实身份证、照片或真实病史；联系人只在确有必须填写时使用获批准的专用测试地址。
- 业务：一次初访预约→线下签到→新建疗程→录入合成现场评估→生成草稿→治疗师复核→下发三个已审核动作→患者完成/报告一次异常→治疗师处理→复评。
- 数值均标记合成，不推导疾病或真实疗效；临床表单与运动量分开。竞品拒绝空联系方式时记录为限制，不随意填真实号码或发送验证码。
- 不上传现有真实 OpenCap 文件；需要数据时只用专门合成包。竞品不支持相同数据类型记 N/A，不当作失败或临床能力为零。

## 度量与结果定义

- 活跃操作时长与系统等待时间分开，保留开始/结束事件、设备/网络/版本；先原始记录，不凭感觉打五分。
- 点击数、必填字段、错误次数仅比较相同任务；官方演示速度不充当自己实测。N/A、权限/付费限制、失败、未执行分开，空值不记0。
- 允许结果：PASS / FAIL / PARTIAL / N_A / BLOCKED / NOT_RUN。只有实际操作且保留证据才能 PASS。
- 不把任务速度直接推导为疗效、准确率或投资回报。不公布厂商未授权的付费截图/视频。
