# S1-03 Core 模拟资料治理工程验收

日期：2026-10-27。基于原工作分支 `feature/reporter-engine-assessment-20261013`，不合并 master、不正式发布。方案见 [实施边界](s1-data-governance-plan.md)。

## 已实现的范围

- 追加 035 迁移，旧患者默认保留业务分类 `REAL`，不从姓名或备注推断真假。`REAL` 不构成医学真实性认证。新增来源列、机构/来源索引、三态约束和独立权限，不改 001–034 校验和、不自动授予角色。
- 患者列表、详情、名单导出、Core 移动员工患者列表和患者分组报告中心显示来源；默认列表排除已归档模拟资料，明确筛选可找回，清空筛选恢复默认语义。旧运行后端未返回来源时不推断来源、不显示治理操作。
- 管理员且满足 `rehab:patient:data-governance` 才可治理。准确编号、预期原状态、理由、界面确认与再次确认；患者行锁和条件更新，同事务审计。仅允许业务→模拟→归档模拟→模拟，不允许模拟降级为业务。
- 归档不删除患者、附件、关联临床记录或账号，不更改治疗阶段。普通编辑不重置来源，普通名单导入拒绝明确标记为模拟的记录，避免无意转换成业务数据。
- 康复工作台/机构经营概览、工作量、风险统计和 Core 移动员工统计排除非 `REAL`；保留机构/可见患者限制和实际工作项、未读通知。空可见范围直接返回零，不把空集合当成无限制。
- 新模拟报告 JSON 带来源，HTML、DOCX 与 PDF 回退文本显示“模拟数据／非临床用途”。患者来源改变后，旧来源不匹配的报告拒绝预览、DOCX/PDF 导出；不覆盖已批准原件，须创建并复核新修订。归档/恢复同属模拟，不移除警示。
- 归档模拟患者不能新发/兑换 Core 患者邀请或继续 Core 绑定会话。此处不冒充独立 HEP 已签发短期令牌即时撤销。
