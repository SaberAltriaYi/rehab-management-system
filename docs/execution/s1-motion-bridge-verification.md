- 原3项隐私回归初次2失败；进一步发现客户端把byte[]以数字数组打印，字符串标记检查会漏报。加“不得进入通用解析器诊断”断言后3/3失败，分别证明snapshot的解析cause、HTTP编码字节日志、null/错误结构的非受控异常。没有把编码后的临床原文当作已脱敏。
- 新 `MotionWorkspaceJson` 使用原Web mapper的独立reader，拒绝null/非对象、重复键及尾随文档；只返回固定提示、不保留原文/cause、不改共享mapper。客户端仍保留响应体积、连接/读取超时、不跟随重定向及可信HTTPS要求。snapshot仍先校验原始UTF-8体积/哈希，再校验schema和机构/患者/疗程/修订，不重新序列化或改写原始JSON。
- 新5项隐私/结构回归：损坏snapshot、实际回环HTTP损坏/503响应、错误envelope/binding、重复键/尾随文档、合法0/负数/单位/备注及原始哈希不变。该约束只保护本工作区JSON路径，不能宣称全仓库所有日志均无隐私风险。
