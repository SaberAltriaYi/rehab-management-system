# S1 身份与日志安全首批验证

实施时间：2026-10-26 至 2026-10-27。范围：S1-02 的确定性身份缺陷、Core 移动端会话与日志隐私，以及已有构建验证。不是整个 S1、S4 或生产发布完成声明。

## 修复及影响

| 问题 | 原因与修复 | 影响范围 |
| --- | --- | --- |
| 请求手机号可以与登录主体无关 | 邀请服务新增会员域 API 校验，要求启用账号及匹配手机号；不跨域直写会员表 | 绑定及患者入口校验；停用/换号必须重新核验 |
| 邀请兑换锁整机构未过期邀请 | 使用已有唯一摘要索引精确查找，软删除也拒绝 | 不改变表结构或历史迁移校验和 |
| 任意声明 caregiver/imported | 本人邀请仅允许 self；监护人保留独立授权门槛 | 客户端不能自授关系，既有业务数据未改 |
| 并发不同邀请可能触发原始 SQL 错误 | 唯一绑定冲突转业务拒绝、事务回滚 | 保持唯一约束，不取消校验 |
| 手机端首次绑定地址错误 | 修正为 `/app-api/app-patient/auth/bind` | 不再落到错误路径 |
| 再次登录还要求一次性邀请 | 已绑定者短信认证后核验当前绑定；首次才兑换邀请 | 不重用已消费邀请，不把会员登录当患者授权 |
| 未找到机构可能变成 tenant 0 | 有限正安全整数校验 | 无效机构在发送短信/登录前拒绝 |
| 患者凭据持久化、退出仅本机清理 | 改页面内存会话、清理旧持久化记录，正常退出尝试服务端注销，失败明确告知 | 刷新/重启重新登录；员工存储策略保持原状 |
| HTTP 401 后界面仍保留登录 | HTTP 和业务 401 均清除会话 | 不扩大权限，不隐藏服务错误 |
| 访问日志可能记录邀请、短信及临床原文 | 认证/康复/会员接口只记元数据；一般 JSON 脱敏失败省略原文，避开通用解析器的原文错误日志 | 控制台及 API 访问日志；独立临床审计仍保留 |

## 测试中发现并修正的问题

H2 `SHUTDOWN` 后 StatementCallback 读取已关闭语句警告导致测试清理失败，改 ConnectionCallback 正常关闭；新日志单测补齐并恢复静态 WebProperties 测试配置。第一次 JSON 脱敏单测暴露通用解析器会先打印原文，已改直接调用解析器并新增日志捕获断言，不能仅检查返回值脱敏。
