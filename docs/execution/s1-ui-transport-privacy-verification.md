## 变更及兼容边界

1. Axios最终错误不再保留原config、headers、request、response body、原message/stack/cause。仅保留固定错误类别、校验后的HTTP状态、已知网络错误码和取消标记；原始错误不再直接打印。已有动作上传的400/401/403不重试、429/5xx可重试分类保持；业务成功和401令牌刷新/排队重放路径未关闭。
2. 加解密失败边界改为固定诊断，底层六处catch不再打印或重抛可能带原输入的异常；可选模块拒绝也不把任意服务端原文作为诊断抛出。没有改变可选加密开关、算法、密钥、TLS校验或现有上传限制。此修补不等于认可旧可选加密算法作为TLS替代。
3. 本管理端刷新令牌改用URL编码POST正文，URL只保留路由；保留原有后端 `@RequestParam` 契约、响应结构和实际令牌校验。租户头在单次请求内捕获，不再修改全局Axios默认租户；不加Cookie、不添加云端请求。其他旧客户端仍可能使用query，不宣称整个产品所有凭据传输均已整改。
4. 新增 `pnpm test:unit`，运行已有登录租户/动作工具用例及本批传输测试，并接入常规CI和正式桌面准备阶段；没有移除或放宽已有构建、审计、签名/许可检查。
