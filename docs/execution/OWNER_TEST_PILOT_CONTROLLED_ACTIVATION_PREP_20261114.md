4. **维护前备份与回滚演练。** 新建 Owner/Core 数据库和附件的受控加密备份，检查清单、权限和哈希，并在独立的临时环境实际恢复验证，记录返回 036、恢复 Owner 开关和配置的步骤。可复用 Mac1 当前服务作为目标，但恢复验证不能在其生产数据上覆盖试验。
