# S1-04 报告请求幂等：实施约定

2026-10-27，基于2c9b955e2c。仅工程和隔离合成验收，现用数据库/账号/患者不变，AI关闭。

1. 可选UUID请求编号；旧客户端不传时保持原有“每次生成新修订”语义。新编号表示明确的新生成意图；同编号重试返回首次成功的相同报告编号、版本和降级结果，不重新生成原文或重复审计。
2. 范围为机构、评估、实际操作人、请求编号摘要。首次成功请求存储规范化请求摘要和结果元数据；不存原始请求编号、病情、令牌或正文。编号相同但生成参数不同拒绝，结果已删除/不可用时拒绝而非创建替代品。
3. 追加036请求账本表，不改035及之前的固定校验和；不自动补历史请求、不删除报告、不新增角色或权限。报告生成、审计、幂等结果同事务，评估行锁序列化并发，账本使用锁定当前读，失败回滚可正常重试。
4. 每次重试先做现有对象权限校验；不因持有编号绕过权限。当前资料来源变化后，旧报告仍受原预览/导出保护。返回原生成结果不等于临床批准，不把新评估内容悄悄写进旧报告。
5. 本批先实现服务端可选契约及H2/MySQL、迁移、全量回归；前端重试编号管理随后接入并单独验证。原系统的开发前端/旧后端不能被声称已经具备此功能。
6. 评估修订一致性、完整业务路径和真实浏览器验收仍单列。上线前必须副本核验036、新备份、恢复及容量检查；当前不部署。
